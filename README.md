# VoiceLedger

一个适配 iOS 的本地语音记账示例工程，包含以下能力：

- 语音记账
- 按月统计
- 历史记录
- 仅支持预设大类：餐饮、交通、购物、娱乐、看病

## 当前语音识别规则

建议说法尽量简洁，例如：

- 餐饮 午饭 35元
- 交通 打车 18块
- 购物 超市 126元
- 娱乐 电影票 49元
- 看病 买药 28元

应用会尝试从一句话中解析：

- 大类：必须属于预设支持范围
- 子信息：如午饭、打车、超市、电影票、买药
- 金额：优先识别阿拉伯数字，也支持简单中文金额，如三十五元

## 数据存储

数据默认保存在设备本地 Documents 目录下的 `expenses.json`。

## 说明

当前环境未安装完整 Xcode，因此工程未在本机做最终 `xcodebuild` 验证。请在完整 Xcode 环境中打开 `VoiceLedger/VoiceLedger.xcodeproj` 后进行签名和真机运行。
